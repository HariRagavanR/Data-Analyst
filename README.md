# Data Analyst Roadmap — Beginner to Job-Ready

## 🎯 Objective
Learn Data Analytics from scratch and become job-ready by developing practical skills in Excel, SQL, Power BI, Python, Statistics, and Business Intelligence.

**Duration:** 8 Weeks  
**Daily Study Time:** 2–3 Hours  
**Target Roles:** Junior Data Analyst, Data Analyst, MIS Analyst, Reporting Analyst, Junior BI Analyst

---

## 🗺️ Learning Roadmap

### Week 1: Excel — Beginner to Intermediate

**Topics**
- Introduction to Data Analytics
- Rows, Columns, Cells, and Data Types
- Sorting and Filtering
- Data Cleaning
- Removing Duplicates
- Handling Missing Values
- Basic Formulas: `SUM()`, `AVERAGE()`, `COUNT()`, `IF()`
- Conditional Formulas: `SUMIF()`, `COUNTIF()`, `SUMIFS()`, `COUNTIFS()`
- Lookup Functions: `XLOOKUP()`, `VLOOKUP()`
- Text and Date Functions
- Pivot Tables and Pivot Charts
- Conditional Formatting

**Practical Task:** Analyze a sales dataset using Excel.

**Deliverable:** Excel Sales Analysis Report

### Week 2: SQL — Fundamentals

**Topics**
- Introduction to Databases and SQL
- Tables, Rows, and Columns
- `SELECT`, `DISTINCT`
- `WHERE`, `ORDER BY`, `LIMIT`
- Operators: `AND`, `OR`, `IN`, `BETWEEN`, `LIKE`
- Handling NULL Values
- Aggregate Functions: `SUM()`, `COUNT()`, `AVG()`, `MIN()`, `MAX()`
- `GROUP BY` and `HAVING`
- `CASE WHEN`

**Practical Task:** Write SQL queries to analyze sales data.

**Deliverable:** 30–40 SQL Practice Queries

### Week 3: SQL — Intermediate and Interview Level

**Topics**
- Primary Keys and Foreign Keys
- `INNER JOIN`
- `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`
- Self Joins
- Subqueries
- Common Table Expressions (CTEs)
- `UNION` and `UNION ALL`
- Date and String Functions
- Window Functions:
  - `ROW_NUMBER()`
  - `RANK()`
  - `DENSE_RANK()`
  - `LAG()`
  - `LEAD()`
- Business Case-Based SQL Problems

**Practical Task:** Solve real-world business questions using multiple tables.

**Deliverable:** 40–50 Additional SQL Problems

### Week 4: Power BI — Fundamentals

**Topics**
- Introduction to Power BI Desktop
- Importing Excel and CSV Files
- Power Query Editor
- Data Cleaning and Transformation
- Data Types
- Table Relationships
- Data Modelling
- Star Schema Fundamentals
- Charts, Tables, and Cards
- Slicers and Filters
- Drill-Down and Interactive Reports

**Practical Task:** Build an interactive sales dashboard.

**Deliverable:** Power BI Sales Dashboard

### Week 5: Power BI — DAX and Business Reporting

**Topics**
- Introduction to DAX
- Measures vs. Calculated Columns
- `SUM()`, `COUNTROWS()`, `DISTINCTCOUNT()`
- `CALCULATE()`, `DIVIDE()`
- `IF()` and `FILTER()`
- Basic Time Intelligence
- KPI Cards
- Revenue and Profit Analysis
- Monthly Sales Trends
- Dashboard Design and Storytelling

**Practical Task:** Create a business performance dashboard.

**Deliverable:** Interactive Business Intelligence Dashboard

### Week 6: Python for Data Analysis and Statistics

**Python Topics**
- Python Fundamentals Revision
- NumPy Basics
- Pandas DataFrames and Series
- Reading CSV and Excel Files
- Data Selection and Filtering
- Sorting Data
- Handling Missing Values
- Removing Duplicates
- Data Type Conversion
- `groupby()`, `merge()`, `pivot_table()`
- Exploratory Data Analysis (EDA)
- Matplotlib Basics

**Statistics Topics**
- Mean, Median, and Mode
- Range, Variance, and Standard Deviation
- Percentages and Ratios
- Distributions and Outliers
- Correlation vs. Causation
- Basic Probability and Sampling

**Practical Task:** Clean and analyze a dataset using Python.

**Deliverable:** Python Data Analysis Notebook

### Week 7: Industry-Oriented Capstone Project

**Project Title:** E-commerce Revenue, Customer Retention & Profitability Intelligence

**Tools**
- Excel
- SQL
- Python and Pandas
- Power BI
- Git and GitHub

**Project Tasks**
- Collect or download a realistic dataset.
- Understand business requirements.
- Clean and validate the data.
- Perform exploratory data analysis.
- Write SQL queries to answer business questions.
- Analyze revenue, profit, and customer behavior.
- Build an interactive Power BI dashboard.
- Identify trends and business problems.
- Write actionable business recommendations.
- Document the complete workflow on GitHub.

**Key Metrics**
- Total Revenue
- Total Profit
- Profit Margin
- Monthly Revenue Growth
- Average Order Value
- Best-Performing Products
- Regional Performance
- Repeat Purchase Rate
- Customer Retention Trends

**Deliverables**
- Cleaned Dataset
- SQL Scripts
- Python Notebook
- Power BI Dashboard
- Project Documentation
- Business Insights and Recommendations

### Week 8: Resume, Interviews, and Job Applications

**Preparation Tasks**
- Create a Data Analyst Resume.
- Organize projects on GitHub.
- Revise Excel formulas and Pivot Tables.
- Practice SQL interview questions.
- Revise Power BI and DAX fundamentals.
- Practice statistics and business case questions.
- Prepare project explanations.
- Practice communicating insights in English.
- Attend mock interviews.
- Apply for entry-level Data Analyst roles.

**Deliverable:** Job-Ready Resume and Project Portfolio

## 📊 Industry-Level Project Ideas

1. **E-commerce Sales Analysis** — Analyze revenue, profit, product performance, and customer behavior.
2. **Customer Churn Analysis** — Identify patterns associated with customer cancellations.
3. **Financial Performance Dashboard** — Analyze revenue, expenses, and profitability.
4. **HR Analytics Dashboard** — Study employee turnover, hiring, and workforce trends.
5. **Supply Chain Analysis** — Analyze inventory, delivery performance, and operational efficiency.

Start with one end-to-end project before building additional projects.
